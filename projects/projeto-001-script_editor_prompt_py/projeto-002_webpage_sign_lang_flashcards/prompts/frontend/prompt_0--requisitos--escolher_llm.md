🎯 Objetivo
Entender qual modelo de LLM é melhor para criar essa feature.

🧠 Prompt Completo
```
Quero criar uma página de flashcards online, seria adicionada a um site já existente. Para cada flashcard, no lado A há:

uma frase em um idioma: português (texto) ou em Libras (vídeo)

E no lado B há:

a tradução da frase no outro idioma

No lado em que o idioma ser português, pode ser mostrada uma imagem relacionada a frase (se o usuário quiser).

O site será feito usando o framework Angular usando Typescript, SCSS e HTML.

Pense em qual dos modelos de LLM citados no documento em anexo é melhor para essa tarefa.
```

🤖 Modelo Utilizado
- Modelo: Claude 4.6 Sonnet
- Adicionais: usado em conjunto com o agente "AdaptaOne26"
